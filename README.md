# 🏠 Emlak Yatırım Hesap Uygulaması

Bu proje, gayrimenkul yatırımlarını rasyonel verilerle analiz etmek için geliştirilmiştir. 
Özellikle Mersin Yenişehir bölgesindeki piyasa verilerini baz alarak, 
kullanıcılara "Kira Çarpanı" üzerinden hızlı karar verme imkanı sunar.

## ✨ Özellikler
- 🟢 **Trafik Işığı Analizi:** Yatırımın risk durumunu renklerle gösterir.
- 📍 **Bölgesel Veri:** Yenişehir mahalle bazlı amortisman takibi.
- 💸 **Pazarlık Desteği:** İdeal fiyata ulaşmak için gereken indirim hesabı.
